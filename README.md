# Toxic Comment Classification

Dự án phân loại bình luận độc hại (toxic comments) nhằm hỗ trợ phát hiện và xử lý ngôn ngữ tiêu cực trong các nền tảng trực tuyến.

## Trạng thái dự án

- Giai đoạn: Setup ban đầu (pre-alpha)
- Chưa có code huấn luyện
- Chưa có thử nghiệm
- Chưa chọn model cuối cùng

## Phạm vi hiện tại

- Thiết lập môi trường làm việc
- Xác định bài toán toxic comment classification
- Chuẩn bị nền tảng cho bước chọn baseline model và chạy thử nghiệm đầu tiên
